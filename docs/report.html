Known beta issues & OS quirks

Sync · Beta server

First device link or sync after idle can take 30–50 seconds

During beta, the sync server runs on Render's free tier and sleeps when idle. Give the first QR link or sync a moment to wake up — after that, syncs are fast.

Android 13–15

"Restricted setting" on Accessibility (Guard) or Notification access

Android blocks those two permissions for apps installed outside Google Play until unlocked once. Open App info for Luna, tap ⋮ › Allow restricted settings, then return to Luna setup. See the setup guide.

Windows & Browser

SmartScreen warning and manual extension install

The beta installer isn't code-signed yet (choose More info › Run anyway), and the browser extension loads via Developer mode › Load unpacked. Keep the unzipped extension folder in place while testing.

Android uninstall

Can't uninstall Luna on Android while Guard Device Admin is on

By design, Device Admin prevents uninstalling Luna during a session. End any active session first, then turn off Device admin for Luna in Android Settings before uninstalling.
